# Room Occupancy Detection

**Live demo:** https://room-occupancy-detection.streamlit.app

Binary classification of room occupancy (occupied / not occupied) from
ambient sensor readings — temperature, humidity, light, CO2, and humidity
ratio — using the UCI "Occupancy Detection" dataset.

## Dataset

Three CSVs under `data/`, following the dataset's canonical split:

- `datatraining.csv` — training set
- `datatest.csv` — validation set, used for model selection
- `datatest2.csv` — held-out final test set

| Column        | Description                                   |
|---------------|------------------------------------------------|
| date          | Timestamp of the reading                       |
| Temperature   | Ambient temperature (°C)                       |
| Humidity      | Relative humidity (%)                          |
| Light         | Illuminance (lux)                              |
| CO2           | CO2 concentration (ppm)                        |
| HumidityRatio | Derived water-vapor / dry-air ratio            |
| Occupancy     | 1 = occupied, 0 = not occupied (target)        |

## Approach

- `notebooks/eda.ipynb` — time-series plots of each sensor and a correlation
  heatmap; light, CO2, and temperature all show a strong relationship with
  occupancy.
- `src/train.py` — trains Logistic Regression, Decision Tree, and Random
  Forest on `datatraining.csv`, evaluates each with 5-fold CV plus the
  `datatest.csv` validation set, picks the best by F1, then reports final
  performance on the untouched `datatest2.csv` holdout.
- `src/predict.py` — classifies a single sensor reading from the command
  line.

## Results

| Model               | Validation Accuracy | Validation F1 |
|---------------------|----------------------|---------------|
| **Logistic Regression** | **0.977**        | **0.969**     |
| Decision Tree        | 0.887                | 0.829         |
| Random Forest        | 0.951                | 0.932         |

Logistic Regression is selected and confirmed on the held-out `datatest2.csv`
set: **accuracy 0.985, F1 0.964**. Full metrics are written to
`models/metrics.json` after training.

## Usage

```bash
pip install -r requirements.txt

python src/train.py
python src/predict.py --temperature 23.2 --humidity 27.3 --light 450 \
    --co2 720 --humidity-ratio 0.0048
```
